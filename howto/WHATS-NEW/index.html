    新能力速览（2026 年 8 月）¶

    本页节选自原项目的 resources.md。

    这轮同步后，中文读者如果只看资源索引，至少要知道这些新入口：

    能力 说明 入口
    /usage-credits 配置额外用量额度；/extra-usage 仍可作为 alias（别名） Slash Commands
    /run / /verify bundled skills，用于启动项目并确认改动真实可用 Skills Guide
    /run-skill-generator 为项目生成专属 run / verify skill Skills Guide
    claude agents --json 输出机器可读的 Agent View 列表 CLI Guide
    /deep-research <topic> 深入研究主题；v2.1.218+ 起仅显式调用 Skills Guide
    /code-review [effort] 内置正确性缺陷审查命令；v2.1.218+ 起在后台 subagent 中运行 Skills Guide
    /simplify 清理型审查命令，关注复用、简化、效率和抽象层级 Skills Guide
    /reload-skills 重新扫描 skill 目录，不需要重启当前 session Skills Guide
    /workflows 查看 dynamic workflows 的运行记录 Advanced Features
    /cd <path> 切换当前 session 工作目录，并尽量保留 prompt cache Slash Commands
    --safe-mode / CLAUDE_CODE_SAFE_MODE=1 禁用 CLAUDE.md、plugins、skills、hooks、MCP servers，用于排查配置问题 Advanced Features
    fallbackModel 配置最多三个 fallback models；--fallback-model 也适用于交互式 session CLI Guide
    disableBundledSkills 隐藏内置 skills、workflows 和 commands Skills Guide
    /plugin list --enabled 按启用状态查看 installed plugins Plugins Guide
    hookSpecificOutput.additionalContext Stop / SubagentStop hook 给 Claude 追加上下文并继续当前 turn Hooks Guide
    CLAUDE_CODE_SESSION_ID 串联 MCP server、hooks 和 Bash 日志的 session 标识 MCP Guide
    claude plugin init <name> 在 .claude/skills 中脚手架本地 plugin；该目录下的 plugin 会自动加载 Plugins Guide
    CLAUDE_CODE_ENABLE_AUTO_MODE / permissions.disableAutoMode 前者从 v2.1.207 起仅保留兼容性且不再生效；Team / Enterprise 管理员可把后者设为 "disable" Advanced Features
    claude auto-mode reset [--yes] 恢复 Auto Mode 默认配置；--yes 跳过确认 CLI Guide
    /fork [prompt] / /subtask <task> / /branch [name] 分别创建独立后台 session、委派会回传结果的 forked subagent、切换到对话副本 Slash Commands
    /fewer-permission-prompts 分析 Bash / MCP 调用并建议 allowlist；旧资料中曾出现过错误命令名 Slash Commands
    autoMemoryEnabled / CLAUDE_CODE_DISABLE_AUTO_MEMORY 控制默认开启的 auto memory Memory Guide
    claude mcp add --scope / add-json 选择 local、project、user 范围或从 JSON 添加 MCP server MCP Guide
    fileCheckpointingEnabled 控制文件快照；最多保留最近 100 个 checkpoints Checkpoints Guide
    outputStyle / statusLine 配置回答风格和终端底部状态栏 Advanced Features
    switchModelsOnFlag 控制安全标记触发时是否自动切换模型 Advanced Features
    anthropics/claude-plugins-community 需手动添加的 Anthropic 社区 plugin marketplace Plugins Guide
    CLAUDE_CODE_MAX_WEB_SEARCHES_PER_SESSION / CLAUDE_CODE_MAX_SUBAGENTS_PER_SESSION 限制每个 session 的 WebSearch 与 subagent spawn 次数，默认均为 200 CLI Guide
    CLAUDE_CODE_MCP_AUTO_BACKGROUND_MS MCP tool call 自动转后台的阈值，默认 120000 毫秒 MCP Guide
    --ax-screen-reader / CLAUDE_AX_SCREEN_READER 启用适合 screen reader 的纯文本渲染模式 CLI Guide
    EnterWorktree 在同一 session 中切换 Claude 管理的 worktree Advanced Features
    claude agents 里的 Ctrl+T 固定后台 session，空闲时优先保留 CLI Guide
    allowAllClaudeAiMcps 组织级允许加载 claude.ai 云端 MCP connectors 的托管设置 MCP Guide
    Agent(agent_type) / CLAUDE_CODE_MAX_SUBAGENT_SPAWN_DEPTH 限制可 spawn 类型并控制深度；v2.1.219+ 默认深度 3，设为 1 可禁用嵌套 Subagents Guide
    CLAUDE_CODE_MAX_CONCURRENT_SUBAGENTS 限制同时运行的 subagents，默认 20 Subagents Guide
    claude-opus-5 默认 Opus 模型，1M context，默认 effort high CLI Guide
    DirectoryAdded /add-dir 或 SDK register_repo_root 新增工作目录后的 hook；当前共 31 个 hook 事件 Hooks Guide
    workflowSizeGuideline dynamic workflows 的建议规模；默认 medium，目标少于 15 个 agents Advanced Features
    sandbox.network.strictAllowlist sandboxed command 访问非 allowlist host 时直接拒绝，不再弹出询问 Advanced Features
    mcp_server_errors headless stream-json init event 暴露 MCP server 配置 / 连接错误 MCP Guide
    --forward-subagent-text stream-json 中转发 subagent 文本；v2.1.219+ 包含深度 2+ 的嵌套输出 CLI Guide
    hook if 条件 用 permission-rule 语法按工具参数继续收窄 hook 匹配 Hooks Guide
    /plugin marketplace 搜索栏 在 marketplace 浏览界面按名称或关键词过滤 plugin Plugins Guide
    enforceAvailableModels 托管策略强制 availableModels 也约束 Default model Advanced Features
    wheelScrollAccelerationEnabled 关闭全屏 renderer 的鼠标滚轮加速 CLI Guide
    footerLinksRegexes 把匹配正则的链接显示成 footer badges CLI Guide
    language 设置回复、语音听写和自动 session title 的偏好语言 CLI Guide
    /doctor 诊断安装、配置和 plugin 健康；v2.1.178+ 起是 flat tree 布局 Slash Commands
    /bug 提交反馈；v2.1.178+ 起必须填写描述 Slash Commands
    Tool(param:value) permission rule 按工具输入参数继续细化匹配 CLI Guide
    嵌套 .claude/agents/ 最近目录优先 monorepo 中同名 agent 采用离当前目录最近的定义 Subagents Guide
    remote session plugin loading remote session 里的 plugin 加载性能在 v2.1.179+ 改进 Plugins Guide
    /review <pr> 审查 GitHub PR；本地 diff 仍用 /code-review [effort] Slash Commands
    claude mcp login/logout 在 CLI 中处理 MCP server OAuth 登录状态，--no-browser 适合 SSH / headless session MCP Guide
    --teammate-mode iterm2 让 teammate 进入 iTerm2 pane，依赖 it2 CLI Subagents Guide
    respondToBashCommands 控制 ! bash 命令输出后是否自动让 Claude 回复 Advanced Features
    Auto Mode 内置意图保护 默认拦截一批破坏性命令，除非当前 session 明确要求 Advanced Features
    sandbox.credentials 阻止 sandboxed commands 读取凭证文件和 secret 环境变量 Advanced Features
    /config key=value 直接从 prompt 设置单个配置项 Advanced Features
    CLAUDE_CODE_MCP_TOOL_IDLE_TIMEOUT 调整 remote MCP tool 无响应 abort 超时 CLI Guide
    MCP 认证启动提醒 / headersHelper 自动刷新 启动时提示仍需认证的 MCP server；HTTP 401 / 403 后动态认证头会自动刷新 MCP Guide
    hook matcher 逗号列表 "Write,Edit" 这类 matcher 会匹配任一列出的工具，并按更精确规则匹配工具名 Hooks Guide
    /plugin unused plugins 提示 /plugin 会提示不再使用的 plugins；plugin name 和 marketplace entry name 不一致时仍能 enable / disable Plugins Guide
    /rewind 跨 /clear /clear 不再是硬边界，可以回到更早 checkpoint Checkpoints Guide
    autoMode.classifyAllShell 让所有 Bash / PowerShell 命令都经过 Auto Mode 分类器 Advanced Features
    claude_code.assistant_response OpenTelemetry log event，用于记录模型回复文本 Advanced Features
    ! bash mode 路径自动补全 输入 ! shell 命令时支持 live file-path autocomplete Advanced Features
    CLAUDE_CODE_DISABLE_MOUSE_CLICKS 禁用 fullscreen mode 的 mouse click / drag / hover，wheel scroll 仍可用 CLI Guide
    Sonnet 5 / claude-sonnet-5 原生 1M context window；是否作为默认模型取决于订阅档位 CLI Guide
    manual permission mode v2.1.200+ 的交互默认名称；旧 default 仍作为 alias 可用 Advanced Features
    /dataviz 图表、dashboard 与调色板设计 bundled skill Skills Guide
    ${CLAUDE_PROJECT_DIR} 在 command / skill 中引用项目根目录绝对路径 Skills Guide
    subagent 默认后台运行 Explore 继承 session 模型，extended thinking 也会继承 Subagents Guide
    MCP roots/list 向 MCP server 暴露启动目录和额外工作目录 MCP Guide
    agent_needs_input / agent_completed 后台 agent 对应的 Notification matcher Hooks Guide
    renames / displayName / defaultEnabled marketplace entry 的迁移、显示和默认启用控制 Plugins Guide
    Summarize up to here 压缩所选位置之前的对话，与 Summarize from here 组成双向压缩 Checkpoints Guide
    askUserQuestionTimeout / enableArtifact 控制询问超时和 Artifact tool 的个人设置 Advanced Features
    CLAUDE_ENABLE_STREAM_WATCHDOG streaming 5 分钟无事件时 abort / retry；设为 0 可禁用 CLI Guide
    --permission-mode auto 直接以 Auto Mode 启动；替代已经移除的 --enable-auto-mode CLI Guide
    sandbox.filesystem.disabled 关闭 filesystem isolation，但保留 network isolation Advanced Features
    CLAUDE_CODE_OTEL_CONTENT_MAX_LENGTH / FORCE_HYPERLINK=0 控制 OTEL 内容截断上限和 footer PR badge 超链接 CLI Guide

    这些名称都是可执行标识或协议字段，不要翻译成中文 key。
